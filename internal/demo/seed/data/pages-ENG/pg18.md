## The window

```yaml
maintenance:
  service: summit-db
  window: "22:00-23:00"
  read_only_banner: "We are tidying the shelves. Orders work again at 23:00."
  steps:
    - alp shop read-only on
    - alp db backup now --verify
    - alp db upgrade --to 18 --analyze
    - alp smoke --env prod
    - alp shop read-only off
```

## Rollback

If the smoke tests fail and the fix is not obvious within 15 minutes, restore the backup taken at the start of the window ([[page:Restore a database backup]]). Orders cannot be lost: the shop is read-only during the window.
